# 网易云音乐黑莓原生第三方：轮易云音乐

## 说明

基于黑莓Cascade框架 已在黑莓Q20和Z10测试

目前处于测试阶段 还有很多没有实现的功能和bug

这是越狱软件 要安装 请先将您的黑莓越狱

目前可以：

播放歌曲

载入歌单

搜索歌曲

本地缓存

载入关注艺人

图标灵感来源：[HomasWSC](https://space.bilibili.com/12722558)

仅供学习使用 禁止倒卖

欢迎加入BlackberryPhonixQQ交流群892633534
